# Projeto 2 — Expressões Numéricas

Programa em C++ para leitura e cálculo de expressões numéricas pelo terminal.

## Funcionalidades

- Inserção de uma expressão numérica.
- Cálculo utilizando fila e pilhas.
- Operações aritméticas: adição (`+`), subtração (`-`), multiplicação (`*`) e divisão (`/`).
- Comparações: maior (`>`), menor (`<`), maior ou igual (`>=`), menor ou igual (`<=`) e diferente (`!=`).

## Como compilar

Com o compilador `g++` instalado, execute na raiz do repositório:

```bash
g++ Projeto/Expressao2.cpp -o projeto2_expressao
```

## Como executar

No Linux ou macOS:

```bash
./projeto2_expressao
```

No Windows, execute o arquivo `projeto2_expressao.exe` gerado após a compilação.

## Uso

No menu, escolha **Inserir expressão** para informar a expressão e, em seguida, **Calcular expressão** para visualizar o resultado. Escolha **Sair** para encerrar o programa.
